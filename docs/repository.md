# Repository

Use [Chest-X-ray-Pneumonia-Classification](https://github.com/XxCPH4xX/Chest-X-ray-Pneumonia-Classification), a private repository with `main` as the default branch.

The development branch is merged into `main` with the uploaded `chest_xray/` dataset preserved, including its nested copy. Original images are unchanged. The existing image blobs are reused; no new dataset upload is needed.

The dataset remains tracked even though `.gitignore` excludes new dataset files. Model weights, experiment outputs, local databases, and secrets stay untracked. The MIT license covers the source code; dataset and pretrained-weight terms are separate.

Continue work in this repository. No separate repository or rewritten history is needed.
